# Capibara Traductor — plugin de Kino

Lector de mangas de [CapibaraTraductor](https://capibaratraductor.com/) para Kino.

Arquitectura **solo pantalla** (como Yuri Online): no expone ítems de vídeo.

- **Autor:** Hotaru Yume (`hotaruyume`)
- **Versión:** 3.0.1
- **apiVersion:** 14

## v3.0.1
- Carga del Inicio con `every` siempre activo (ya no se queda en «Cargando…»).
- Buscador: parsea `/scan/manga/slug` y lee el query del formulario.
- AppBar simple (sin barra duplicada).

## Uso
Menú de Kino → **Capibara** → Inicio o Buscar → obra → capítulo.
