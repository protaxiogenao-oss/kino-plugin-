# Capibara Traductor — plugin de Kino

Lector de mangas de CapibaraTraductor (solo pantalla).

- **Autor:** Hotaru Yume (`hotaruyume`)
- **Versión:** 3.0.2
- **apiVersion:** 14

## v3.0.2
- El catálogo se carga **al abrir** la pantalla (`open`), no solo con el temporizador.
- Esqueletos mientras carga; botón «Recargar» si queda vacío.
- Mensaje claro si falla el host / la red.

## Uso
Menú Kino → Capibara. Acepta el host `capibaratraductor.com` si te lo pide.
